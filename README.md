# JavaLab · 10-нұсқа

[Сайтты ашу](https://kuatakylbek44-ai.github.io/java-data-lab-10/)

Java Data Science практикалық жұмысына арналған қазақша интерактивті сайт.

- **Commons Math:** статистика, корреляция және сағат бойынша балл болжамы.
- **Weka J48:** интерактивті шешім ағашы, 10-fold тексеру, қателер матрицасы.
- **Smile K-Means:** hours + score бойынша 3 кластер, сүзгілер және кластер орталықтары.
- **Java:** негізгі код үзінділері және толық жобаны жүктеу.
- **Түсіндіру:** жұмысты сабақта таныстыруға арналған төрт қадам.

## Жергілікті ашу

`index.html` файлын браузерде ашыңыз немесе:

```sh
python -m http.server 4173
```

Содан кейін http://localhost:4173 мекенжайына өтіңіз. Сыртқы тәуелділіктер, API кілті және құрастыру қадамы қажет емес.

## Файлдар

- `index.html`, `styles.css`, `app.js` — сайт.
- `data.js` — деректер, дайын коэффициенттер, кластерлер және код үзінділері.
- `assets/students.csv` — бастапқы 30 жол.
- `assets/Main.java` — тексерілген 97 жолдық Java бағдарламасы.
- `assets/Java_10_nusqa.zip` — толық Java жобасы.

Сайт Java/Weka/Smile модельдерін браузерде қайта үйретпейді. Ол орындалған Java жұмысының нәтижелерін түсіндіреді. Регрессия дайын коэффициенттермен есептеледі; J48 демонстрациясы толық деректерге үйретілген ағаштың шарттарын қайталайды. 83,3% — бөлек 10-fold тексеру нәтижесі. Кластерлер: k=3, hours+score, seed=42, масштабтау жоқ.

Қозғалысты азайтуды таңдаған құрылғыларда анимация шектеледі. Пернетақтамен басқару және телефонға бейімделген көрініс бар. Бірдей координаталардағы нүктелердің tooltip-ы барлық студент нөмірін көрсетеді.

GitHub Pages: `main` тармағы, `/` түбірі. `.nojekyll` қолданылады.
