Неге графикте Smile, ал тапсырмада K-Means жазылған?+

Smile — машиналық оқытуға арналған Java кітапханасы. K-Means — сол кітапханадағы кластерлеу алгоритмі. Сондықтан Smile терезесінде K-Means нәтижесінің көрсетілуі дұрыс.

83,3% пен R² = 0,547 бір мағына ма?+

Жоқ. 83,3% — J48 жіктеуінің 10-fold тексерудегі дұрыс болжам үлесі: 25/30. R² = 0,547 — регрессия балл өзгерісінің шамамен 54,7%-ын түсіндіретінін көрсетеді. Бұлар әртүрлі модельдердің әртүрлі көрсеткіштері.

Неге нәтижелер терминалда, ал график бөлек терезеде?+

System.out.printf және System.out.println мәтінді терминалға шығарады. Smile-дың plot.window() әдісі графикті жеке терезеде ашады. Кодта екеуі де бар; графикті кішірейтіп, Terminal бөлімін көруге болады.
